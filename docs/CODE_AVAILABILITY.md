# Code availability

Analysis code, frozen non-patient configuration files, disclosure-safe aggregate source data, and release-validation tests are publicly available under the MIT License at https://github.com/FENG1567/ap-claims-transformer-reproducibility (release `v1.0.0`). Reproducing the full NRD and MIMIC-IV analyses requires independently authorized access to the controlled datasets and the non-redistributed frozen model bundle described in `RESTRICTED_DATA.md`; no patient-level data, credentials, or restricted artifacts are included in the repository.
