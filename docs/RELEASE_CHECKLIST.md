# Public release checklist

- [x] No raw NRD or MIMIC-IV data.
- [x] No patient-, encounter-, hospital-, prediction-, or bootstrap-replicate rows.
- [x] No checkpoint, fitted binary, archive, credential, token, or SSH key.
- [x] Formal v7 MIMIC runtime and v2 adapter included; v1-v6 runtimes excluded.
- [x] Corrected 2022 temporal analysis and technical-amendment code retained.
- [x] Public aggregate source data and figure PDFs/SVGs included.
- [x] Python and R dependencies documented.
- [x] Public smoke test and release verifier included.
- [x] File manifest and SHA-256 checksum list included.
- [x] Absolute-path, secret-pattern, identifier-column, and large-file checks completed.
- [x] Public GitHub repository URL recorded in `README.md` and `CITATION.cff`.
- [ ] Add the journal DOI and an archival software DOI if they are assigned later.
- [ ] Obtain institutional confirmation before redistributing any trained checkpoint or fitted binary.
